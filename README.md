# 《我真没想重生啊》互动章节

双击打开 `index.html` 即可游玩，不需要安装依赖。通关开篇后点击“继续主线”进入第二段：港城同学聚会、班费处理、第一次逃课和校园快递代理机会。关系与竞选支持会影响后续文字及阶段结果；“保存进度”会保存在浏览器本机，结局图鉴跨游玩记录。

本版覆盖陈汉升、王梓博、萧容鱼、胡林语、沈幼楚、高嘉良、梁美娟七位人物，从高考后的港城推进到入学两周后的同学聚会、第一次逃课与校园快递代理机会。原著关键节点保留，玩家选择影响人物回应和经营路线。竞选准备、替沈幼楚补班费的处理方式、同学对话回应及谈代理策略中的可选分支属于同人假设，不代表原著正史。新增课堂、网吧与快递网点原创场景图。

## 文件

- `index.html`：交互剧情与页面
- `assets/`：人物立绘、场景图
- `dist/`：静态站点构建目录
